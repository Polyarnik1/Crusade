# Crusade

Геймификация жизни в стиле тёмного фэнтези и пиксель-арта. Выходишь из дома, замыкаешь маршрут — и всё внутри петли становится твоей землёй. Земли складываются в княжество или королевство, за подвиги дают славу, титулы и регалии.

Сейчас это первая версия в виде сайта (PWA). Позже её можно завернуть в приложение для Android.

## Что уже есть

- **Карта и захват земель.** GPS-трек, петля засчитывается, когда возвращаешься к своему следу (ближе 25 м, длина от 120 м). Самопересекающийся маршрут режется на отдельные уделы. Петли сливаются в одни владения.
- **Королевство.** После первого похода предлагается основать государство: название, форма правления (княжество, королевство, герцогство, вольный город, а за регалии ещё орден, марка и империя), цвет, знамя (форма, узор, символ, второй цвет) и облик башен.
- **Соседи.** Чужие земли подсвечены цветом их владельца, по желанию с красным пунктирным контуром. Если замкнуть петлю по чужой земле, граница сдвигается в твою пользу. Пока нет сервера, рядом живут три демо-соседа (их можно выключить).
- **Слава и титулы.** От «Бродяги» до «Императора»: слава за уделы, километры, привычки, поход дня и недельный вызов.
- **Задания.** Поход дня засчитывается сам по карте, свои привычки можно добавлять и удалять.
- **Регалии.** 17 штук, каждая с пиксель-артом и цитатой. Делятся на подвиги и курьёзы, у каждой есть редкость. За 3, 6, 8, 10 и 12 регалий открываются новые цвета, формы правления, узоры, символы и башни.
- **Летопись.** Журнал всего, что произошло. Потом рядом появится таверна, то есть общая лента.
- **Герой.** Имя, «о себе», любимые книги, фильмы и игры, витрина регалий.
- **Настройки.** Облик башен, красный контур соседей, демо-соседи, цель похода дня, скрытие зоны вокруг дома, тестовый поход, экспорт и импорт прогресса, кнопка доната (пока заглушка).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173, в локальной сети тоже доступно
npm run build    # сборка в dist/
```

Геолокация в браузере работает только по HTTPS или на `localhost`. Чтобы проверить на телефоне, удобнее всего GitHub Pages (см. ниже).

### Тестовый поход

В **Герой → Настройки → Для разработки** включи «Тестовый поход». Тогда кнопка на карте запустит симуляцию: за ~40 секунд персонаж пройдёт две петли рядом с тобой. Так удобно смотреть захват, регалии и основание королевства без прогулки.

## Публикация на GitHub Pages

1. В репозитории открой **Settings → Pages** и в **Source** выбери **GitHub Actions**.
2. Каждый пуш в `main` соберёт и выложит сайт на `https://polyarnik1.github.io/Crusade/`.

## Как устроено

```
src/
  game/        логика: состояние и сохранение, захват петель (turf), уровни, регалии, косметика, демо-соседи, GPS
  art/         пиксель-арт регалий и башен, генератор знамён
  components/  общие элементы интерфейса
  screens/     экраны: карта, задания, регалии, летопись, герой, настройки, редактор королевства
```

- Прогресс хранится в `localStorage` (ключ `crusade.v1`).
- Карта: Leaflet и тёмные тайлы CARTO на данных OpenStreetMap, тонированные под зимнюю ночь.
- Шрифты: [Tiny5](https://fonts.google.com/specimen/Tiny5) для пиксельного текста (с нормальной кириллицей) и Inter для мелкого текста.
- Весь пиксель-арт нарисован вручную сеткой символов (`src/art/arts.ts`), палитра в `src/art/Pixel.tsx`.

## Ограничения версии 0.1

- Нет сервера: соседи демо, прогресс живёт в одном браузере (есть экспорт и импорт).
- В браузере GPS засыпает вместе с экраном. Пока идёт поход, приложение просит не гасить экран (Wake Lock). Фоновый трекинг появится в приложении.
- Донат и регалия «Меценат» ждут платёжки.

## Что дальше

1. Сервер (например, Supabase): аккаунты, настоящие соседи, таверна, скрытие зоны вокруг дома для чужих глаз.

3. Античит для GPS (скорость, телепорты, проверка на транспорт).
4. Больше регалий, сезонные события, кланы и союзы королевств.

## Арт и звук

- **Пиксельные сцены** регалий и шапок экранов рисуются процедурно: `tools/scenes/` (движок с палитрами, дизерингом и тёплым светом). После правок: `npm run art:scenes` — пересоберёт `src/art/scenes.gen.ts` и превью в `shots/`.
- **Частицы** (снег, искры, светлячки, пепел, пыль) — `src/art/SceneArt.tsx`, рисуются по сетке пикселей сцены.
- **Звуки** синтезируются через Web Audio без файлов: `src/audio/sfx.ts`. Включаются и настраиваются в «Герой → Настройки».
